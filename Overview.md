# Space Travel and Spacecraft Trajectories

A collaborative repository for our 10-week Durham University orbital mechanics project.

## Organisation

Each week has its own folder containing Python code and a README explaining the work completed.

## How to navigate

1. Open the folder corresponding to the relevant week.
2. Read that week's README to understand the tasks and methods.
3. Open the relevant Python file to view the implementation.
4. Check the code comments for explanations of important calculations.

## File naming

- Use descriptive names such as `earth_mars_transfer.py`.
- Avoid names such as `test1.py` or `final_final.py`.
- Keep all code in the appropriate week's folder.
- Record changes and improvements through GitHub commits.

## Collaboration

All group members can contribute code. Please clearly explain new files and avoid deleting other members' work without discussing it.
